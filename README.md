# Historias-Basadas-en-Arquetipos-

Este repositorio contiene un proyecto académico desarrollado para la asignatura de Comunicación, correspondiente a la carrera de Ciencia de Datos.

El trabajo consiste en la elaboración de 5 historias originales, cada una construida en torno a un arquetipo distinto. Cada relato se complementa con su respectivo documento crítico, en el cual se justifica por qué la historia responde a dicho arquetipo y se explica su fundamento basado en datos.

El propósito de este repositorio es recopilar y presentar de forma organizada los textos creativos junto con sus análisis críticos, como parte de los requisitos de la asignatura.
